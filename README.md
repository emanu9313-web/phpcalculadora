# Calculadora CI

[![PHP Continuous Integration](https://github.com/emanu9313-web/phpcalculadora/actions/workflows/php-ci.yml/badge.svg?branch=main)](https://github.com/emanu9313-web/phpcalculadora/actions/workflows/php-ci.yml)

Proyecto de calculadora en PHP con pruebas unitarias en PHPUnit e integracion continua usando GitHub Actions.

## Operaciones implementadas

- Suma
- Resta
- Multiplicacion
- Division
- Control de division por cero con `InvalidArgumentException`

## Ejecutar pruebas

```bash
composer install
./vendor/bin/phpunit tests
```
